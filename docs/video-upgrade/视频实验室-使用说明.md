# 知映视频实验室（5 分钟试验版）

打开本机 `http://127.0.0.1:4177/video-lab.html`，或在同一 Wi‑Fi 的手机浏览器打开 `http://192.168.100.200:4177/video-lab.html`（IP 变化时按电脑当前 WLAN 地址替换）。

页面可输入任意主题，使用已有 DeepSeek API 生成 5 章课程大纲，并逐章生成 4 个画面事件，共 20 幕。也可点击“查看已生成的 CPU / GPU 示例”立即加载真实模型生成的方案。示例原始结构见 `video-lab-cpu-sample.json`。

点击镜头后可以上传一张图片。图片仅留在当前浏览器，用作该镜头的图片层；字幕和其他图形由 Canvas 绘制。首次播放会请求本机配音，镜头长度按实际音频时长调整，每幕至少 15 秒；配音失败的镜头可静音预览。

导出通过浏览器实时录制画布和配音，再调用现有 `/api/convert` 转为 MP4。约 5 分钟视频需要保持页面打开并等待至少与片长相近的录制时间。转码失败时提供 WebM。当前没有自动图片生成模型，图片需要手动上传；也没有完成 5 分钟全片导出的端到端人工验收。这是验证导演 Agent、时间轴和图片叠加的试验页面，画面能力与参考视频仍有差距。

若服务关闭，在项目目录运行 PowerShell：

```powershell
$env:PORT='4177'
$env:HOST='0.0.0.0'
npm start
```
