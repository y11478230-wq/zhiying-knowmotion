# 任务二：通用矢量动画与画面引擎

## 目标

建立能服务不同知识主题和长视频的矢量动画引擎。画面以可编辑对象组成，对象可以跨镜头、跨章节连续运动、变形、拆解和组合；AI 负责选择表达方式和编排动作，渲染器负责准确执行。

## 负责人

动画 / 画面引擎负责人（成员 B）

## 工作范围

1. 定义通用场景模型：画布、图层、对象 ID、几何/文本/路径、状态、动作、时间、镜头和章节边界。
2. 提供主题无关的基础动作：出现、消失、移动、缩放、描边、变色、高亮、沿路径运动、数值变化、形态变换、分解、组合、镜头平移和局部缩放。
3. 建立可扩展的矢量对象类型：点线面、曲线、箭头、坐标轴、流程节点、时间轴、公式片段、代码行、标签和通用路径。数学专用对象作为能力包，不把整个引擎写死为数学动画。
4. 设计主题能力包接口：在统一动作协议上注册学科对象、规则和校验。例如函数曲线可从表达式采样，物理轨迹可按参数计算，代码演示可显示状态变化；不能可靠计算的效果需明确降级成示意图。
5. 支持长视频场景状态持久化与分段渲染。每章可独立渲染，也可从前一章接收对象状态；跳转、暂停、续渲染时同一时间输入必须得到同一画面。
6. 支持可选图像素材层：图像模型生成插画或背景后作为独立图层，可做裁切、缩放、景深和遮罩；文字、公式、曲线、坐标和关键数值必须由矢量层绘制，避免图片模型生成错误文字或公式。
7. 建立知映视觉系统：浅色主题、对象颜色语义、字幕安全区、留白、动效节奏和镜头运动规范。每镜不强制套同一张卡片模板。
8. 与 A 锁定动作 Schema 与能力声明，向 C 提供确定性、可按时间采样的渲染入口。
9. 按 `参考视频-生成Agent规范.md` 支持照片、透明背景插画与矢量层混排：图片可进入、移出、缩放、裁切、遮罩和聚焦，矢量箭头、数字与标签能叠加并随图片对象同步移动。

## 交付物

- `vector-scene-schema.json`：对象、状态、动作、时间、章节和素材字段定义。
- `animation-capabilities.json`：基础引擎与学科能力包支持的对象、动作、参数限制和校验方式。
- `visual-style.md`：颜色语义、字体、字幕区域、镜头节奏与动效规范。
- 可运行的矢量渲染预览和按时间采样接口。
- 可跨镜头连续变换、可保存和恢复的长视频场景样例。
- 图片素材层与矢量层组合样例，演示“具体图片 → 标注关系 → 抽象图解”的连续镜头。

建议每个动作包含 `id`、`target`、`type`、`startTime`、`duration`、`from`、`to`、`easing`；长视频内使用全片时间或明确的章节相对时间，并提供章节偏移换算规则。

## 验收标准

- 用至少 5 类不同内容验证基础引擎，至少覆盖数学、自然科学、编程、历史地理和概念流程；不能只运行数学样例。
- 同一对象跨镜头及跨章节保留身份和状态，可连续变换。
- 任意时间点可重复渲染出一致画面；支持长片跳转、分段渲染和失败续跑。
- 公式、文字、线条、图表和数值均可编辑，坐标关系与计算结果正确。
- 无对应能力时给出机器可读错误或有说明的示意降级，不能静默变成文字卡片。
- 手机比例清晰可读；镜头动作服务讲解，不加入无关装饰动画。
- 同一例子跨镜头复用相同图片对象；图片转场与矢量标注位置稳定，关键区域不会被字幕遮住。

## 协作边界

成员 B 对渲染器、对象模型、动作能力、连续状态和视觉规范负责。成员 A 决定教学上需要呈现的对象与动作；成员 C 负责把动作时间映射到配音并输出视频。A 不应要求不存在的能力，B 也不能改变知识含义。
