# 示例文字稿：第一行 C 语言代码是怎样运行的？

目标观众：第一次接触 C 语言的学习者。预计时长：约 82 秒。结构参考用户提供的教学视频：提问引入、关键术语、操作界面、运行验证、回顾总结。画面与旁白按镜头对应。

配音建议：用“专业讲解 · 云扬”的自然语速。每句重点术语前后保留短停顿，镜头紧跟语音结束切换。`stdio.h` 和 `printf` 的实际读法可在每幕“配音读法”中单独修改，屏幕字幕仍保持代码的标准写法。实际导出时长会按合成语音自动调整。

画面中的代码：

```c
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
```

终端演示（Windows，已安装 GCC）：

```powershell
gcc main.c -o main.exe
.\main.exe
```
